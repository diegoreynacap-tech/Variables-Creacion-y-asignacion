▸ ¿Qué es HTML?

HTML estructura el contenido con etiquetas entre < >. No programa acciones: organiza qué es cada cosa.

Todo documento sano tiene el mismo esqueleto:

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi página</title>
  </head>
  <body>
    <p>Contenido visible</p>
  </body>
</html>

<!DOCTYPE html> le avisa al navegador que esto es HTML moderno. <html lang="es"> envuelve todo e indica el idioma. <head> es la "cabeza": información sobre la página que no se ve (la codificación <meta charset="UTF-8"> y el <title> que aparece en la pestaña). <body> es el "cuerpo": todo lo que el usuario ve.

🧠 Casi toda etiqueta se abre y se cierra: <title>…</title>. Las que no cierran (<meta>) son vacías.

☣ PROTOCOLO DE PURIFICACIÓN

Escribí un documento HTML completo y sano que tenga:
  • La declaración <!DOCTYPE html> en la primera línea.
  • <html> con el atributo lang="es".
  • Un <head> con <meta charset="UTF-8"> y un <title> con algún texto.
  • Un <body> con un párrafo que diga exactamente: Sector asegurado.
